description: "ATLShield is a machine learning-powered public safety platform that predicts hourly crime volumes for Atlanta neighborhoods and recommends optimal patrol strategies for law enforcement. Built as a Flask API backed by trained Random Forest models (Regressor for crime volume prediction, Classifier for patrol strategy), the system processes real Atlanta crime data from 2021–2025. Key features include hourly crime intensity visualizations with color-coded risk levels, average daily crime analytics per neighborhood, and real-time predictions integrated into Tableau dashboards via TabPy. The backend was deployed on AWS EC2 for scalable, production-grade performance."
