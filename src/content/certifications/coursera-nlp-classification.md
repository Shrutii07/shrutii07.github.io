This course covers the fundamentals of Natural Language Processing, focusing on classification and vector space models. It provides hands-on experience with implementing NLP algorithms and understanding how machines process human language.

- Sentiment analysis with logistic regression
- Naive Bayes for text classification

- Text preprocessing and feature extraction
